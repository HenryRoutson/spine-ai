To answer your first question: asyncio.gather itself does not have a hardcoded limit, but the underlying Windows operating system and your network libraries do.
If you are using aiohttp or older versions of Python, Windows uses a networking method called select(), which has a hardcoded limit of exactly 64 concurrent sockets (connections). If you throw 100 tasks at asyncio.gather, Python tries to open 100 TCP sockets at the exact same millisecond, Windows panics, and you get a ValueError: too many file descriptors in select() or a dropped connection limit error.

By default, standard Python libraries (requests, aiohttp, standard urllib) use HTTP/1.1. In HTTP/1.1, 100 parallel requests require 100 separate physical TCP connections.
HTTP/2, however, natively supports multiplexing. This means you open one single TCP connection to OpenRouter, and you stream all 100 of your parallel requests and responses simultaneously back and forth inside that single pipe.
