BoundaryML - https://boundaryml.com/ - Boundry ML does seem interesting. it's a library for helping with prompting, with a bit more type safety, and the schema validation we're looking to use. They've also done some of the nondetemrinism / deterministic / probablisitic logic we're using. BAML Workflow View does have some overlap. It's not a full 1.0 version yet. They're trying to replace traditional coding language, while our approach is more to wrap the existing approach with current langauges like python to be more abstracted. 
instructor - https://useinstructor.com/ - This is a library to return results in schemas, like pydantic, but it only supoprts openAI clients. you need to make a new client for each response model. It's not to the scale of what we're trying to build. we also want to support non open ai style apis.
Vellum AI - https://www.vellum.ai/ - I've used this a bit. It's kind of a custom agent for local use for employees in their daily tasks. It's not meant for scalable production pipelines.
LlamaExtract (part of LlamaCloud) - While LlamaExtract does have schema based extraction, it only does document ingestion.
